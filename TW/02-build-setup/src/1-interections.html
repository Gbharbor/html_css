Ações e Interações com Tailwind CSS

Nesta aula, vamos explorar diferentes estados e interações que podem ser aplicados aos elementos com Tailwind CSS, como hover, active, focus, disabled, group-hover e dark mode.

Exemplo de hover: ao passar o mouse sobre o botão, a cor muda. Neste caso, a alteração só acontece em telas médias ou maiores por causa do prefixo md:.

Exemplo de active: enquanto o botão estiver a ser clicado, a cor de fundo muda.

Exemplo de focus: quando o campo recebe foco, a aparência muda.

Exemplo de disabled: quando o campo está desativado, podemos aplicar estilos específicos.

Exemplo com file: é possível estilizar o botão interno de um campo de upload.

Exemplo de group-hover: quando o elemento pai recebe hover, os elementos filhos também podem mudar.
