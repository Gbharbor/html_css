CSS: Cascade, Units and Measurements

Nesta aula, estudamos a cascata do CSS e os principais tipos de unidades de medida: absolutas, relativas e viewport.

1. Cascata no CSS

A cascata define qual estilo terá prioridade quando mais de uma regra tenta aplicar formatação ao mesmo elemento.

Ordem básica de prioridade:

  • External CSS - arquivo externo com .css
  • Internal CSS - estilo dentro da tag <style>
  • Inline CSS - estilo direto no elemento com style=""

O inline normalmente tem mais prioridade que o internal e o external.

2. Medidas absolutas

As medidas absolutas têm um valor fixo. Elas não dependem diretamente do tamanho da tela ou do elemento pai.

  • px - pixels
  • pt - pontos
  • in - polegadas
  • cm - centímetros
  • mm - milímetros

A unidade mais usada no desenvolvimento web costuma ser px.

3. Unidades de medida relativas

As medidas relativas se ajustam de acordo com outro valor, como o tamanho da fonte do elemento pai ou da raiz do documento.

3.1 em

A unidade em é relativa ao tamanho da fonte do elemento pai.

Exemplo: se o elemento pai tiver font-size: 20px, então:

  • 1em = 20px
  • 2em = 40px
  • 0.5em = 10px

3.2 rem

A unidade rem é relativa ao tamanho da fonte do elemento raiz, normalmente a tag <html>.

Ela é muito útil porque mantém mais consistência no site inteiro. Se o tamanho base da página mudar, os elementos em rem acompanham essa alteração.

Por isso, rem costuma ser uma das melhores opções para trabalhar com fontes e espaçamentos.

3.3 %

A porcentagem representa uma parte do tamanho do elemento pai.

Exemplo: width: 50% significa que o elemento ocupará metade da largura do seu contêiner pai.

4. Unidades de viewport

As unidades de viewport usam como referência o tamanho visível da janela do navegador.

4.1 vh

vh significa viewport height, ou seja, altura da área visível da tela.

  • 100vh = altura total da tela
  • 50vh = metade da altura da tela

Essa unidade é muito usada em banners, seções principais e menus laterais que precisam ocupar toda a altura da tela.

4.2 vw

vw significa viewport width, ou seja, largura da área visível da tela.

  • 100vw = largura total da tela
  • 50vw = metade da largura da tela

Exemplo: se um elemento tiver width: 50vw, ele ocupará metade da largura da janela.

5. Resumo

  • px = valor fixo
  • em = relativo ao elemento pai
  • rem = relativo ao elemento raiz
  • % = relativo ao tamanho do elemento pai
  • vh = relativo à altura da tela
  • vw = relativo à largura da tela
