Aula 3 - Viewport

Aqui aprenderemos sobre o viewport.


Com initial-scale=1.0, definimos o nível inicial de zoom da página em dispositivos mobile.

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Com user-scalable=no, o utilizador não consegue dar zoom no mobile.

<meta name="viewport" content="width=device-width, user-scalable=no">

Aula 4 - Imagens responsivas: picture e source


<picture>
  <source media="(min-width: 650px)" srcset="foto3.png">
  <source media="(min-width: 450px)" srcset="foto2.png">
  <img src="foto1.png" alt="Imagem responsiva">
</picture>

A tag picture permite mostrar imagens diferentes conforme o tamanho da tela. Já a tag source define qual imagem será usada em cada condição.

Aula 5 - Imagens responsivas: propriedade object-fit

object-fit: fill;

A imagem preenche o espaço definido, mas pode ficar distorcida dependendo do tamanho escolhido.

object-fit: contain;

A imagem é ajustada sem distorcer. Pode sobrar espaço em branco dentro da área disponível.

object-fit: cover;

A imagem mantém a proporção e cobre todo o espaço disponível, podendo cortar partes dela. É uma das opções mais usadas.

object-fit: scale-down;

É semelhante ao contain, mas reduz a imagem apenas quando necessário, tentando manter uma boa qualidade.

Aula 6 - CSS @media: como funciona 1

Com @media, conseguimos criar regras específicas para determinados tamanhos de tela ou condições. É como se criássemos outro conjunto de estilos para situações específicas. 


Aqui está uma configuração normal do body:

body {
    background-color: gray;
}

Com esse comando, o body muda quando a tela atingir determinado tamanho:

@media (max-width: 600px) {
    body {
        background-color: red;
    }
}

Aula 7 - CSS @media: como funciona 2

Aqui entenderemos como estilizar para impressão. Se usar media="all", funcionará em todas as condições. 


Estas regras acontecerão apenas quando a página for impressa:

@media print {
    h1 {
        display: none;
    }

    table, td {
        border: 3px solid black;
    }
}

Aula 9 - Aspect-ratio no @media

É uma técnica menos utilizada, mas importante para entender.


Neste caso, quando a tela tiver proporção de 1 para 1, ou seja, formato quadrado:

@media (aspect-ratio: 1/1) {
    body {
        background-color: red;
    }
}

Aqui, quando a tela tiver proporção de 2 para 1,
ou seja, a largura for o dobro da altura:

@media (aspect-ratio: 2/1) {
    body {
        background-color: rgb(0, 110, 255);
    }
}

E aqui, quando a tela tiver proporção de 1 para 2,
ou seja, a altura for o dobro da largura:

@media (aspect-ratio: 1/2) {
    body {
        background-color: rgb(0, 255, 47);
    }
}

Aula 11 - Função var() em media query


Para criarmos variáveis no CSS, usamos o :root:

:root {
    --bg-color: rgb(74, 239, 9);
    --bg-second: rgb(13, 38, 177);
    --font-color: rgb(231, 21, 21);
}

body {
    background-color: var(--bg-color);
}

Se a variável não existir ou der algum erro,
podemos passar um valor de fallback:

h1 {
    color: var(--font-color, blue);
}

.container {
    background-color: var(--bg-second);
    color: var(--font-color);
}

  

Aqui criamos uma media query e alteramos a variável,
sem precisar mudar elemento por elemento:

@media (max-width: 450px) {
    :root {
        --font-size: 15px;
    }
}

Aula 13 - Funções max() e min()

Em resumo, conseguimos definir o tamanho da imagem de acordo com o tamanho da tela. 


img {
    width: max(50%, 400px);
}

No max(), o navegador escolhe o maior valor entre os que foram definidos.

No min(), é o contrário: o navegador escolhe o menor valor entre os definidos. 


img {
    width: min(50%, 600px);
}

Aula 14 - Função calc()

Esta função calcula tamanhos. Por exemplo: podemos usar uma largura em percentagem, mas descontar um espaço fixo em pixels, mantendo melhor controlo da responsividade. 


O calc() define um valor dinâmico.

Exemplo:
quando a tela diminuir, o elemento continuará respeitando
os 40px descontados do total.

.container {
    width: calc(100% - 40px);
    background-color: grey;
    height: 150px;
}
