Name e Value

O atributo name identifica o campo. O atributo value define o valor enviado ou o texto exibido no botão.

Atributos importantes dos inputs

placeholder

É um texto de exemplo que fica dentro do campo. É muito útil em páginas de login e formulários.

autofocus

Abre a página já com o cursor pronto para digitar no campo que tiver o atributo autofocus.


size

O atributo size define a largura visível do campo com base na quantidade aproximada de caracteres.

maxlength

Define o número máximo de caracteres permitidos no campo.

Digamos que seja uma senha de banco que só aceite 4 caracteres. Basta usar maxlength="4".

required

O atributo required torna o campo obrigatório.

autocomplete

Se não quiser que apareçam sugestões automáticas, basta adicionar autocomplete="off" no input desejado.
