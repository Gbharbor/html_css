Aula 11 - Tags fieldset e legend

O que são e para que servem?

As tags fieldset e legend ajudam a organizar melhor um formulário. O fieldset agrupa campos relacionados dentro de uma mesma área. Já a tag legend funciona como o título desse grupo de campos.
