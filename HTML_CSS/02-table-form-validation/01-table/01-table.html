Tabelas no HTML

Tag table

A tag tr representa uma linha da tabela, enquanto as células (colunas) são representadas por td.
Vamos definir uma largura de 400px para a tabela.

quadrado1 quadrado2
quadrado3 quadrado4

Cabeçalho da tabela

Em vez de td, podemos usar th (table header).
Por uma questão estrutural, também podemos utilizar thead e tbody. Isso não altera o visual, mas organiza melhor o código.

item 1 item 2 item 3
1 2 3
1 2 3 
EDITANDO TABLE:
Aqui definimos a largura da tabela e uma borda sólida.

.tabela {
   width: 400px;
   border: 1px solid black;
}

EDITANDO COLUNAS (TD E TH):
Por padrão, a borda aparece apenas ao redor da tabela.
Para aplicar nas células, estilizamos td e th.

td, th {
   border: 1px solid black;
   padding: 10px;
   color: white;
   text-align: center;
}

EDITANDO CABEÇALHO DA TABELA:
Aqui alteramos apenas o fundo do thead.

table thead {
   background-color: rgb(12, 10, 10);
}

EDITANDO CORPO DA TABELA:
Aqui estilizamos o tbody.

table tbody {
   background-color: rgb(43, 12, 12);
}

EFEITO HOVER:
Quando passamos o mouse sobre uma linha.

tbody tr:hover {
   background-color: rgb(6, 20, 81);
}

LINHAS PARES:
Aplicando estilo apenas em linhas pares.

tbody tr:nth-child(even) {
   background-color: rgb(124, 95, 196);
}

REMOVENDO NEGRITO DO TH:

th {
   font-weight: normal;
}
