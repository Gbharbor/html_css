Aula 1 - Validações nativas (1/2)

required

Campo obrigatório. Não permite enviar o formulário vazio.

<input type="text" name="nome" required>

minlength

Define a quantidade mínima de caracteres.

<input type="text" name="nome" required minlength="2">

Aula 2 - Validações nativas (2/2)

step

Define o intervalo permitido entre os valores.

Idade
<input type="number" name="idade" step="2">

min e max

Definem o valor mínimo e máximo permitido.

<input type="number" name="idade" min="18" max="120">

Aula 3 - Estados de validação com CSS

:invalid

O seletor :invalid aplica estilo quando o campo estiver inválido, ou seja, quando não atender às regras definidas no HTML. 

input:focus:invalid {
  border: 2px solid red;
}

:valid

O seletor :valid aplica estilo quando o campo estiver válido, ou seja, quando estiver preenchido corretamente. 

input:focus:valid {
  border: 2px solid green;
}

Usamos junto com :focus para o estilo aparecer apenas quando o utilizador estiver interagindo com o campo, evitando que ele já carregue vermelho logo ao abrir a página.
