Componentes de Formulário

Nesta aula vamos ver alguns elementos muito usados em formulários: select, textarea, button e label.

Select

A tag select cria uma lista de opções para o utilizador escolher. Dentro dela usamos a tag option, que representa cada item da lista. 

<form action="paginalogin.html" method="get">
    <select name="ordenacao">
        <option value="bestseller">mais vendidos</option>
        <option value="last" selected>recentes</option>
    </select>
    <input type="submit" value="ver resultado">
</form>

No exemplo abaixo, usamos o atributo selected para deixar uma opção marcada por padrão quando a página abrir.

Select com múltipla escolha

Se quisermos permitir que o utilizador escolha mais de uma opção, podemos usar o atributo multiple. O atributo size define quantas opções ficam visíveis ao mesmo tempo. 

<select name="order" size="4" multiple>
    <option value="expensive">mais caro</option>
    <option value="bestseller">mais vendidos</option>
    <option value="last">recentes</option>
    <option value="cheap">mais barato</option>
</select>

Textarea

A tag textarea cria uma área maior de texto, muito usada para descrições, mensagens, comentários ou observações. 

<form action="paginalogin.html" method="get">
    <textarea name="descricao"></textarea>
    <input type="submit" value="enviar">
</form>

Button

A tag button também pode ser usada para enviar um formulário. Em muitos casos, ela cumpre a mesma função de um input type="submit". 

<form action="paginalogin.html" method="get">
    <button type="submit">Texto do botão</button>
    <input type="submit" value="texto do submit">
</form>

Label

A tag label serve para identificar e associar um texto a um campo do formulário. Isso melhora a organização e também a acessibilidade.

Exemplo usando for e id

Neste caso, o atributo for do label deve ter o mesmo valor do id do input. 



<form action="paginalogin.html" method="get">
    <label for="nome">Nome Completo</label>
    <br>
    <input type="text" name="nome" id="nome">
    <br>
    <input type="submit" value="Enviar">
</form>

Outro exemplo com checkbox

Também podemos associar o label a um checkbox. Assim, ao clicar no texto, o campo também é ativado. 

<input type="checkbox" id="aceite">
<label for="aceite">Clique para aceitar os termos de privacidade.</label>

Input dentro do label

Existe ainda outra forma de usar label: colocando o input dentro dele. Isso também cria a associação entre o texto e o campo. 

<label>
    Nome Completo:
    <br>
    <input type="text" name="nome">
</label>
