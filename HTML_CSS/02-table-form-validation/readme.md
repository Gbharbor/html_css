## 📘 Aulas

- **01** — Tabelas (`table`, `tr`, `td`, `th`)
- **02** — Formulários (`form`, `action`, `method`)
- **03** — Inputs (text, email, number, checkbox, radio)
- **04** — Componentes (`select`, `textarea`, `button`)
- **05** — Estrutura (`label`, `fieldset`, `legend`)
- **06** — Validação (`required`, `min`, `max`, `:valid`, `:invalid`)
