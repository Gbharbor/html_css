No Grid, algumas propriedades são definidas no container, enquanto outras devem ser definidas nos itens.

Por exemplo: podemos querer que os 3 primeiros itens fiquem na primeira linha e que o item 4 ocupe toda a linha abaixo deles.

Trabalhando com GAP

O gap define o espaçamento entre os itens do Grid. 

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  column-gap: 10px;
  row-gap: 20px;
  gap: 10px 10px;
}

Nesse exemplo, criamos 3 colunas. Como não definimos manualmente as linhas, o Grid cria novas linhas automaticamente conforme os itens forem sendo adicionados.

Também podemos definir colunas fixas: 

grid-template-columns: 100px 100px 100px;

Ou deixar uma coluna diferente das outras: 

grid-template-columns: 100px 200px 100px;

Também é possível misturar tamanhos automáticos com fixos: 

grid-template-columns: auto auto;
grid-template-columns: auto 200px 100px;

Grid Template Rows

A propriedade grid-template-rows funciona de forma parecida com grid-template-columns, mas controla a altura das linhas. 

grid-template-rows: 100px 200px 50px 300px;

Se não definirmos as linhas manualmente, o Grid calcula a altura automaticamente com base no conteúdo.

Unidade FR

A unidade fr divide o espaço disponível de forma proporcional. 

width: 500px;
grid-template-columns: 1fr 1fr 1fr;

Nesse caso, o espaço disponível será dividido em 3 partes iguais.

Se uma coluna tiver 2fr, ela ocupará o dobro do espaço de uma coluna com 1fr. 

width: 500px;
grid-template-columns: 1fr 2fr 1fr;

Mesmo sem largura fixa no container, o fr continua se adaptando ao espaço disponível.

Usando Repeat

A função repeat() serve para deixar o código mais curto e organizado. 

.container {
  display: grid;
  grid-template-columns: repeat(3, 100px);
}

Isso é equivalente a: 

grid-template-columns: 100px 100px 100px;

Outro exemplo: 

grid-template-columns: repeat(3, 1fr);

Também podemos misturar repeat() com outros valores: 

grid-template-columns: repeat(3, 1fr) 200px;
grid-template-columns: 100px repeat(3, 1fr) 200px;

E ainda repetir grupos de valores: 

grid-template-columns: repeat(2, 100px 200px);
grid-template-columns: repeat(3, 100px) repeat(2, 20px);

Auto-fill

O auto-fill permite criar colunas automaticamente conforme houver espaço disponível. 

grid-template-columns: repeat(auto-fill, 200px);

Grid Auto Rows

A propriedade grid-auto-rows define a altura padrão das linhas criadas automaticamente. 

grid-auto-rows: 200px;

Porém, se algum item tiver muito conteúdo, ele pode ultrapassar essa altura. Para resolver isso, usamos minmax().

Minmax

grid-auto-rows: minmax(50px, 200px);

Nesse caso, a linha terá no mínimo 50px e no máximo 200px.

Se quisermos deixar a altura máxima automática: 

grid-auto-rows: minmax(50px, auto);

Também podemos usar minmax() nas colunas: 

grid-template-columns: repeat(3, minmax(100px, 300px));

Posicionamento no Grid

Assim como no Flexbox, podemos alinhar o Grid dentro do container. 

.container {
  display: grid;
  gap: 10px;
  grid-template-columns: repeat(3, 200px);
  background-color: #ccc;
  justify-content: end;
}

Também existem propriedades como:

  • justify-content
  • align-items
  • align-content

Essas propriedades controlam como o grid e seus itens se posicionam dentro do espaço disponível.

Mesclando itens em colunas

Podemos fazer um item ocupar mais de uma coluna usando: grid-column-start e grid-column-end. 

.item1 {
  grid-column-start: 1;
  grid-column-end: 3;
}

Aqui, o item começa na linha 1 e termina na linha 3, ocupando 2 colunas.

Mesclando itens em linhas

A lógica para linhas é parecida: 

.item3 {
  grid-column-start: 2;
  grid-column-end: 3;
  grid-row-start: 2;
  grid-row-end: 4;
}

Assim, o item ocupa uma coluna e se estende por mais de uma linha.

Os outros itens não desaparecem: eles apenas são reposicionados no espaço restante.

Outros exemplos de posicionamento

.item7 {
  grid-column-start: 3;
  grid-column-end: 4;
  grid-row-start: 1;
  grid-row-end: 5;
}

.item5 {
  grid-column-start: 1;
  grid-column-end: 3;
  grid-row-start: 4;
  grid-row-end: 5;
}

Forma resumida: Grid Column e Grid Row

Podemos resumir as propriedades anteriores desta forma: 

.item1 {
  grid-column: 1 / 3;
  grid-row: 1 / 3;
}

Também podemos usar span: 

.item1 {
  grid-column: 1 / span 2;
  grid-row: 1 / span 3;
}

Grid Area

A propriedade grid-area resume:

  1. grid-row-start
  2. grid-column-start
  3. grid-row-end
  4. grid-column-end
.item1 {
  grid-area: 1 / 1 / span 2 / span 2;
}

.item1 {
  grid-area: 1 / 1 / 3 / 3;
}

.item6 {
  grid-area: 4 / 2 / 6 / 4;
}

Grid Template Areas

Aqui usamos nomes para organizar visualmente o layout. 

.container {
  display: grid;
  gap: 10px;
  grid-template-areas:
    "item1 item2"
    "item3 item4";
}

Se quisermos que o item 1 ocupe duas colunas: 

.container {
  display: grid;
  gap: 10px;
  grid-template-areas:
    "item1 item1"
    "item2 item3"
    "item4 .";
}

O ponto . representa uma célula vazia.

Outro exemplo: 

.container {
  display: grid;
  gap: 10px;
  grid-template-areas:
    "item1 item1"
    "item2 item3"
    "item4 item3";
}
.item1 { grid-area: item1; }
.item2 { grid-area: item2; }
.item3 { grid-area: item3; }
.item4 { grid-area: item4; }
