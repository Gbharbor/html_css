Seletores CSS avançados

Seletor por atributo - parte 1 e 2

Resumo

O seletor por atributo permite estilizar elementos com base em atributos específicos. Por exemplo, se quisermos editar um campo com required, basta usar colchetes: 

[required] {
  /* estilos */
}

Também podemos selecionar por tipo de input: 

input[type=text] {
  /* estilos */
}

input[type=password] {
  /* estilos */
}

Quando o valor do atributo é texto personalizado, como name="usuario", o ideal é usar aspas: 

input[name="usuario"] {
  /* estilos */
}

Também podemos combinar seletores para deixar a regra mais específica: 

.minha-div [required] {
  /* estilos */
}

#meu-id input[type="text"] {
  /* estilos */
}

Selecionando links por partes do atributo href

Podemos selecionar links que contenham determinada palavra no href. Exemplo: 

a[href*="economia"] {
  /* estilos */
}

O operador *= significa “contém”.

Se quisermos selecionar tudo que começa com https, usamos: 

a[href^="https:"] {
  /* estilos */
}

O operador ^= significa “começa com”.

Se também quisermos diferenciar links que começam com http:, podemos fazer: 

a[href^="http:"] {
  /* estilos */
}

a[href^="https:"] {
  /* estilos */
}

Já para selecionar links que terminam com determinado valor, usamos $=. 

a[href$="html"] {
  /* estilos */
}

O operador $= significa “termina com”.

O seletor :empty serve para selecionar elementos que não possuem conteúdo. 

div:empty {
  /* estilos */
}

Se quiser esconder esse elemento vazio, por exemplo: 

div:empty {
  display: none;
}

Seletor de primeira letra e primeira linha

::first-letter

Permite estilizar apenas a primeira letra de um elemento de texto, como um parágrafo. 

p::first-letter {
  /* estilos */
}

Seletor de primeiro e último elemento

Podemos usar :first-child e :last-child para estilizar o primeiro e o último elemento dentro de um grupo.

Isso é muito útil, por exemplo, para criar bordas arredondadas em um menu formado por vários blocos.

.
.

div:first-child {
  /* estilos */
}

div:last-child {
  /* estilos */

Seletor negativo

O seletor :not() serve para selecionar tudo, menos o que for especificado.

Exemplo: aplicar estilos em todos os elementos, exceto os parágrafos. 

body :not(p) {
  /* estilos */
}

Também pode ser usado com classes, ids ou outros seletores.

Seletor NTH

O seletor :nth-child() permite selecionar um elemento específico de acordo com sua posição. 

div:nth-child(2) {
  /* estilos */
}

Se quisermos contar de baixo para cima, usamos :nth-last-child(). 

div:nth-last-child(2) {
  /* estilos */
}

Seletores ::before e ::after

Com ::before e ::after, conseguimos criar conteúdo visual antes ou depois de um elemento.

Exemplo simples com texto: 

div::before {
  content: "->";
  background-color: blue;
}

Se quisermos criar uma forma, como um quadrado, precisamos lembrar que esses pseudo-elementos são inline por padrão. Por isso, usamos display: inline-block. 

div::after {
  content: "";
  display: inline-block;
  width: 100px;
  height: 100px;
  background-color: blue;
}

Exemplo de balão com ::after

Olá, tudo bem?

Podemos usar ::after para criar a “seta” do balão. 

.balao {
  background-color: blue;
  display: inline-block;
  color: white;
  padding: 20px;
  border-radius: 20px;
}

.balao::after {
  content: "";
  width: 20px;
  height: 20px;
  background-color: blue;
  display: block;
  position: absolute;
  margin-top: 20px;
}

Para transformar esse elemento em triângulo, removemos largura, altura e background e passamos a usar bordas: 

.balao::after {
  content: "";
  display: block;
  position: absolute;
  margin-top: 20px;
  border: 20px solid;
  border-color: blue transparent transparent transparent;
}

Alterando a posição da cor na propriedade border-color, conseguimos mudar a direção da seta.

Exemplo com a seta na lateral direita: 

.balao::after {
  content: "";
  display: inline-block;
  position: absolute;
  margin-left: 20px;
  top: 25px;
  border: 20px solid;
  border-color: transparent transparent transparent blue;
}

RGBA

O formato rgba() permite definir uma cor com transparência. O último valor representa a opacidade.

Imagem de fundo

body {
  background-image: url("bg.jpg");
  background-size: cover;
  background-position: center;
}

Um uso muito comum de RGBA é criar uma camada escura sobre a imagem de fundo. 

.overlay {
  background-color: rgba(0, 0, 0, 0.5);
  position: fixed;
  top: 0;
  bottom: 0;
  left: 0;
  right: 0;
}

Transform - parte 1

scale()

A função scale() altera a escala do elemento. 

transform: scale(1);

O valor 1 representa o tamanho normal. Valores menores diminuem, e valores maiores aumentam. 

transform: scale(0.5);
transform: scale(2);

Também podemos definir escala horizontal e vertical separadamente: 

transform: scale(1, 0.5);

Ou usar: 

transform: scaleX(1.2);
transform: scaleY(0.8);

Transform - parte 2

rotate()

A função rotate() rotaciona o elemento em graus. 

transform: rotate(30deg);

Também é possível usar valores negativos. 

div {
  background-color: red;
  width: 100px;
  height: 100px;
  position: fixed;
  right: 0;
  bottom: 0;
  transform: rotate(90deg);
}

skew()

A função skew() distorce o elemento. 

transform: skew(20deg);

Também podemos usar: 

transform: skewX(20deg);
transform: skewY(25deg);
transform: skew(20deg, 25deg);

Estilizando o placeholder

Podemos estilizar o texto do placeholder com o pseudo-elemento ::placeholder. 

.input::placeholder {
  color: #999;
  font-size: 14px;
}
