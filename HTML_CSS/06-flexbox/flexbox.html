Flexbox: introdução, direções e alinhamentos

Por que o Flexbox foi criado?

Antes do Flexbox, era comum usar float: left para colocar elementos lado a lado. Isso até funcionava em casos simples, mas era uma solução limitada e pouco flexível.

Por exemplo, se quisermos criar duas divs uma ao lado da outra, poderíamos fazer assim: 

.square1, .square2 {
width: 150px;
height: 150px;
background-color: blue;
margin: 15px;
float: left;
}

O problema aparece quando tentamos usar width: 50% com margens. Mesmo com margens pequenas, os elementos podem quebrar de linha, porque a soma das larguras e margens ultrapassa o espaço disponível. 

.square1, .square2 {
width: 50%;
height: 150px;
background-color: blue;
margin: 0;
float: left;
}

Foi justamente para resolver esse tipo de limitação que o Flexbox foi criado.

Ativando o Flexbox

Para usar Flexbox, criamos um elemento container e aplicamos nele display: flex.

Sem isso, as divs ocupam o espaço de forma normal. Quando ativamos o Flexbox, os itens passam a seguir as regras de layout flexível.

Direção dos elementos

Por padrão, o Flexbox organiza os itens em linha, ou seja, um ao lado do outro. Isso equivale a flex-direction: row.

As principais opções são:

  • row → itens em linha
  • column → itens em coluna
  • row-reverse → linha da direita para a esquerda
  • column-reverse → coluna de baixo para cima

Preenchendo o espaço com flex: 1

Mesmo que o conteúdo dos elementos seja pequeno, podemos fazer com que eles ocupem o espaço disponível de forma proporcional usando flex: 1.

Nesse caso, todos os itens passam a dividir igualmente o espaço do container.

1
2
.container3 div {
flex: 1;
background-color: blue;
margin: 5px;
padding: 5px;
font-size: 18px;
}

Proporções diferentes

Se quisermos que um item ocupe mais espaço que os outros, basta aumentar seu valor de flex.

Por exemplo, um item com flex: 2 ocupa o dobro do espaço de um item com flex: 1.

.container4 {
display: flex;
background-color: grey;
flex-direction: row;
margin: 10px;

flex: 1;
background-color: rgb(159, 51, 221);
margin: 10px;
padding: 10px;

}

flex: 2;
}

Aula 2 - Flexbox: alinhamentos

Tamanhos fixos

Se quiser definir um tamanho fixo para os itens, pode usar width. Porém, para isso funcionar corretamente, normalmente é preciso remover o flex: 1.

Se não houver espaço suficiente, os itens tentam se ajustar para continuar na mesma linha.

flex-wrap: wrap

Para permitir que os itens quebrem para a linha de baixo, usamos flex-wrap: wrap.

O valor padrão é nowrap, ou seja, sem quebra de linha.

flex-flow

A propriedade flex-flow junta duas propriedades em uma: flex-direction e flex-wrap. 

flex-flow: row wrap;

Centralizando os itens

justify-content

Alinha os itens no eixo principal. Se a direção for row, esse eixo é horizontal.

align-items

Alinha os itens no eixo cruzado. Se a direção for row, esse eixo é vertical.

Para centralizar totalmente os itens dentro do container, normalmente usamos: 

justify-content: center;
align-items: center;
1
2
3

Outros valores de justify-content

  • flex-start → itens no início
  • flex-end → itens no final
  • center → itens no centro
  • space-around → espaço ao redor dos itens
  • space-between → primeiro no início, último no final, espaço entre os do meio

E se a direção for column?

Quando usamos flex-direction: column, os eixos mudam:

  • justify-content passa a atuar na vertical
  • align-items passa a atuar na horizontal

Aula 3 - Flexbox: alinhamentos avançados

align-self

A propriedade align-self serve para alterar o alinhamento de apenas um item específico dentro do container.

Isso é útil quando todos os elementos seguem um alinhamento geral, mas um deles precisa ficar em posição diferente.

Valores comuns

  • flex-start
  • flex-end
  • center

order

A propriedade order altera a ordem visual dos itens.

Por padrão, todos os itens têm order: 0.

  • order: 1 → vai para depois dos itens com ordem 0
  • order: 2 → vai ainda mais para o fim
  • order: -1 → vai para antes dos itens padrão

align-content

A propriedade align-content só funciona quando:

  • o container tem flex-wrap: wrap
  • os itens ocupam mais de uma linha

Ela controla o alinhamento do conjunto de linhas dentro do container.

Valores comuns

  • flex-start → linhas no início
  • flex-end → linhas no final
  • center → linhas no centro
  • space-between → linhas distribuídas com espaço entre elas
  • space-around → linhas com espaço ao redor
