HTML - Conceitos Gerais

Compatibilidade com HTML5

Assunto

Basicamente, podemos criar as nossas próprias tags e elas podem funcionar visualmente.

Porém, navegadores antigos como o Internet Explorer 8 já não são mais uma referência atual e tinham limitações no reconhecimento de tags HTML5.

Atributo data-*

Assunto

Basicamente, é uma informação extra para o navegador ou para o programador.

Por isso usamos esse atributo, e ele funciona com qualquer tag.

É muito utilizado em situações mais complexas, principalmente com JavaScript.

WebKit

Aqui vamos aprender um conceito teórico.

Vamos ver o nome de algumas engines, que são motores de renderização usados pelos navegadores.

  • IE: Trident
  • Edge (antigo): EdgeHTML
  • Firefox: Gecko
  • Opera: WebKit/Blink
  • Safari: WebKit
  • Chrome: WebKit/Blink

Meta tag (social sharing)

São recursos para que redes sociais consigam criar uma prévia melhor do link, mostrando mais informações quando ele é compartilhado.

Algumas propriedades podem ser específicas de certas plataformas, mas a ideia geral é a mesma.
