CSS - Efeitos e Recursos Visuais

Normalize.css

Em resumo, padroniza o comportamento do site em diferentes navegadores, corrigindo diferenças e inconsistências visuais.

É um arquivo que podes incluir no projeto, funcionando como uma biblioteca muito usada para normalização de estilos.

Bordas arredondadas

Usamos a propriedade border-radius para criar bordas arredondadas.

Degradê (Gradient)

Alguns navegadores antigos podem não suportar certos gradientes, por isso é interessante definir uma cor de fundo padrão.

Em alguns casos, utilizavam-se múltiplas propriedades para compatibilidade entre navegadores.

Animações, sombras e transições

Criamos animações com @keyframes. O nome da animação não precisa ser o mesmo nome da classe.

box-shadow é usado para elementos, enquanto text-shadow é usado para textos. 


@keyframes exemplo {
   0% {
      background-color: red;
      margin-top: 0px;
      margin-left: 0px;
      box-shadow: -15px 0px 5px black;
   }
   25% {
      background-color: yellow;
      margin-top: 0px;
      margin-left: 200px;
      box-shadow: 0px -15px 5px black;
   }
   50% {
      background-color: blue;
      margin-top: 200px;
      margin-left: 200px;
      box-shadow: 15px 0px 5px black;
   }
   75% {
      background-color: green;
      margin-top: 200px;
      margin-left: 0px;
      box-shadow: 0px 15px 5px black;
   }
   100% {
      background-color: red;
      margin-top: 0px;
      margin-left: 0px;
      box-shadow: 0px 0px 0px rgb(81, 79, 79);
   }
}

.exemplo {
   width: 150px;
   height: 150px;
   background-color: red;
   animation-name: exemplo;
   animation-duration: 10s;
   animation-delay: 1s;
   animation-iteration-count: 1;
   margin: auto;
   margin-top: 100px;
   box-shadow: 10px 10px 5px;
   border-radius: 75px;
   transition: all 1s linear;
}

.exemplo:hover {
   width: 200px;
   height: 200px;
   border-radius: 100px;
   background-color: grey;
}

.exemplo2 {
   width: 100px;
   height: 100px;
   background-color: red;
   transition: all 0.5s linear;
}

.exemplo2:hover {
   background-color: blue;
   width: 200px;
}

Quebra de palavra (word-wrap)

Quando colocamos uma palavra muito grande, ela pode ultrapassar o espaço do elemento.

this paragraph contains nothing especialadsadsadasdasddadsda

Podemos resolver isso com propriedades de quebra de palavra, como word-wrap ou overflow-wrap.
