# HTML - Estrutura e Semântica

Repositório com aulas práticas de HTML e CSS focadas na estruturação de páginas e uso correto de semântica.

---

## 📂 Estrutura

``` estrutura-semantica/
├── 01-structure/
├── 02-semantic/
├── 03-general/
├── 04-media/
├── 05-visual-effects/
├── 06-text-semantic/
```

---

## 📘 Aulas

* **01** — Estrutura básica (`html`, `head`, `body`)
* **02** — Semântica (`header`, `section`, `article`, `footer`)
* **03** — Elementos gerais (divs, organização, blocos)
* **04** — Media (`img`, `audio`, `video`)
* **05** — Efeitos visuais (CSS básico, cores, espaçamentos)
* **06** — Texto e semântica (`p`, `strong`, `em`, tipografia)

---

## 🎯 Objetivo

Praticar os fundamentos de HTML e CSS voltados para:

* Estruturação correta de páginas
* Uso de semântica
* Organização de conteúdo web
