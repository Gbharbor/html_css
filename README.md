# HTML, CSS e Tailwind

Repositório com exemplos práticos e exercícios focados nos fundamentos de **HTML**, **CSS** e **Tailwind CSS**.

Este material serve como base para construção de interfaces modernas e como preparação para projetos front-end mais avançados.

---

## 📂 Estrutura

### HTML

* Estrutura de páginas
* Elementos semânticos
* Formulários
* Links, imagens e tabelas

### CSS

* Seletores e propriedades
* Box Model
* Flexbox e Grid
* Responsividade
* Animações

### Tailwind CSS

* Configuração do ambiente
* Uso de classes utilitárias
* Customização via `tailwind.config.js`

---

## Objetivo

Consolidar os fundamentos essenciais do front-end, permitindo:

* Criar interfaces bem estruturadas e organizadas
* Aplicar boas práticas de estilização
* Entender diferentes abordagens de layout (Flexbox, Grid e Tailwind)
* Evoluir para projetos mais complexos com frameworks modernos

---

## 📎 Contexto

Este repositório complementa outros projetos do portfólio, onde esses conceitos são aplicados em cenários reais de desenvolvimento.
